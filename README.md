# Invert_Grasslands_Diversity
Analysis of invertebrate diversity in grasslands

R scripts, project and data for invertebrate grasslands diversity analysis

# Content Description 
1. Data: Data from surveys
2. Scripts: Scripts for processing and analysis of data
3. Results: Results from analysis included in article
